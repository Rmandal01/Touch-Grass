# Touch-Grass / GrowFlow

GrowFlow is a productivity garden: focused work grows your plant, doomscrolling wilts it.

Two frontends share one Supabase backend:

- Web app + Chrome extension — in [`growflow-web/`](growflow-web/). See
  [growflow-web/README.md](growflow-web/README.md) for full setup, run, and deploy
  instructions.
- Flutter phone app — planned in [CLAUDE.md](CLAUDE.md).

To run the web app + extension, start here: **[growflow-web/README.md](growflow-web/README.md)**.
